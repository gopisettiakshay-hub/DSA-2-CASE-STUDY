# DSA-2-CASE-STUDY
# Data Structures and Algorithms Case Studies

This repository contains case studies and Java implementations of fundamental Data Structures and Algorithms used in real-world applications such as database indexing, library management systems, network design, and range query processing.

## 📚 Contents

### CO1: BST and AVL Trees
**Case Study:** SmartLibrary Book Management System

#### Topics Covered
- Binary Search Tree (BST)
- AVL Tree
- Tree Rotations (LL, RR, LR, RL)
- Tree Height Analysis
- AVL Insertion and Deletion

#### Scenario
A university library stores book accession IDs using a BST. To improve search efficiency, the system is upgraded to an AVL Tree.

#### Complexity
| Operation | BST | AVL |
|-----------|-----|-----|
| Search | O(n) worst case | O(log n) |
| Insert | O(n) worst case | O(log n) |
| Delete | O(n) worst case | O(log n) |

---

### CO2: B-Trees, B+ Trees, Segment Trees and Fenwick Trees
**Case Study:** DataBank Transaction Management System

#### Topics Covered
- B-Tree
- B+ Tree
- Segment Tree
- Fenwick Tree (Binary Indexed Tree)

#### Scenario
A banking organization manages millions of customer transactions and requires efficient indexing and range-query operations.

#### Complexity
| Data Structure | Main Use | Complexity |
|---------------|----------|------------|
| B-Tree | Database Indexing | O(log n) |
| B+ Tree | Storage Systems | O(log n) |
| Segment Tree | Range Queries | O(log n) |
| Fenwick Tree | Prefix Sum Queries | O(log n) |

---

### CO3: Graph Traversal and Minimum Spanning Trees
**Case Study:** NetConnect Solutions Network Design

#### Topics Covered
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Prim's Algorithm
- Kruskal's Algorithm
- Minimum Spanning Tree (MST)

#### Scenario
A communication company designs an efficient network between offices while minimizing installation costs.

#### Complexity
| Algorithm | Purpose | Complexity |
|-----------|----------|------------|
| BFS | Graph Traversal | O(V + E) |
| DFS | Graph Traversal | O(V + E) |
| Prim's Algorithm | Minimum Spanning Tree | O(E log V) |
| Kruskal's Algorithm | Minimum Spanning Tree | O(E log E) |
